Class: EntityInstance ​

Defined in: entities/src/entityInstance.ts:265

One live entity.

The active component set is the base components plus every active component group, with a later group replacing an earlier component of the same name. It changes only through EntityInstance.applyEffects, so an event's effects land on a tick boundary.

applyDamage() ​

applyDamage(event, amount, sensorEvents?): DamageResult

Defined in: entities/src/entityInstance.ts:598

Applies an amount of damage that has already been sensed.

The sensor's events fire first, whatever the amount. Then the amount comes off the health attribute, and minecraft:on_hurt, minecraft:on_hurt_by_player and minecraft:on_death fire in that order. onDamageProcessed observers run last, for a blow that did no damage too.
