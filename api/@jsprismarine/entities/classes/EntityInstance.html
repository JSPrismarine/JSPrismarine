Class: EntityInstance ​

Defined in: entities/src/entityInstance.ts:220

One live entity.

The active component set is the base components plus every active component group, with a later group replacing an earlier component of the same name. It changes only through EntityInstance.applyEffects, so an event's effects land on a tick boundary.

damage() ​

damage(event): DamageResult

Defined in: entities/src/entityInstance.ts:497

Applies one damage event.

The first component that answers onDamage decides the amount, which is what minecraft:damage_sensor does. An immunity component then turns the cause aside, after the sensors have seen it, so a sensor still fires its event on damage the entity ends up ignoring. What is left comes off the health attribute, and minecraft:on_hurt, minecraft:on_hurt_by_player and minecraft:on_death fire in that order.
