Enumeration: PacketIdentifier ​

Defined in: protocol/src/PacketIdentifier.ts:9

The id every Bedrock packet travels under, as the first ten bits of its header.

One member per packet the 1.26.51 (protocol 2193) documentation lists, with the value the documentation gives it; the gaps are ids Mojang has retired. Derived from the [cereal:packet] property of each *Packet.json schema in the release metadata. https://mojang.github.io/bedrock-protocol-docs/1.26.51/
