FullContainerName ​

Defined in: protocol/src/structure/FullContainerName.ts:17

A FullContainerName: which container a slot belongs to. Container Name is a ContainerEnumName (ContainerUiId in @jsprismarine/minecraft) written as one byte, then Dynamic ID tells apart several open containers of the same kind.

On the wire Dynamic ID is an optional: one presence byte, then a little-endian uint32 when present. The 2193 schema lists it as a required uint32 and only records the optional from 2207 on, but gophertunnel at 2193 and the live 1.26.50 client both write the presence byte. ContainerRegistryCleanupPacket and the ItemStackRequest slot infos use it. https://mojang.github.io/bedrock-protocol-docs/1.26.51/types/full-container-name/
