JSPrismarine / @jsprismarine/prismarine / GenerationRegion

Class: GenerationRegion ​

Defined in: prismarine/src/world/generators/datadriven/GenerationRegion.ts:268

A rectangular chunk window of Java block states.

States are held as indices into a per-region palette, so the buffer is two bytes a block rather than one object reference. surfaceChunk and featureWorld project the two seams the generation stages read it through; the two interfaces spell getBlock differently, so neither is implemented on the class itself.

transfer() ​

transfer(): GenerationRegionTransfer

Defined in: prismarine/src/world/generators/datadriven/GenerationRegion.ts:407

Packs the region for postMessage and gives its buffers up.

The region is spent once this returns, whether or not the caller posts the payload: the buffers are already promised to the other side. What travels is the palette and three flat arrays, which is 18 microseconds for a column against 76 structured-cloned.

withStructureWrites<T>(place): T

The marks ride along in the patches as RegionChunkPatch.structureBlocks. A later write at the same position by a feature of this pass takes the mark away again, because that feature saw the structure's block and Java would have let it through too.
