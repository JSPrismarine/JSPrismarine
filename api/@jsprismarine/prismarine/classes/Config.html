getChunkHost() ​

getChunkHost(): "process" | "in-process"

Defined in: prismarine/src/config/Config.ts:545

Where chunk generation workers run.

process, the default, starts a separate generation process at a lowered operating system priority and falls back to threads in the server process when it cannot. in-process keeps the threads in the server process. Any other value is treated as the default.
