getBreakTime() ​

getBreakTime(item, _server): number

Defined in: packages/prismarine/src/block/Block.ts:133

How long, in seconds, the block takes to break.

Hardness on its own is not that time. Vanilla scales it by whether the tool in hand can actually harvest the block: 1.5x when it can, 5x when it cannot - which is why dirt takes 0.75s by hand and stone 7.5s, rather than the 0.5s and 1.5s their hardness alone would suggest. Returning the hardness unscaled is what made the cracking animation, whose speed the server derives from this, run out well before the block gave way.

Defined in: packages/prismarine/src/block/Block.ts:184

What this block yields, as chances rather than as code.

The hook a block overrides when what it drops is not simply itself and not certain - seeds from grass, flint from gravel, a sapling from leaves. A table can be read against the game and rolled with a chance source of the caller's choosing; a Math.random() in the block, which is how gravel's flint was written, can be neither.
