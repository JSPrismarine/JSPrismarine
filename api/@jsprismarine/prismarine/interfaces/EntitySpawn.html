JSPrismarine / @jsprismarine/prismarine / EntitySpawn

Interface: EntitySpawn ​

Defined in: prismarine/src/world/EntitySpawn.ts:12

A mob world generation decided should exist, recorded rather than created.

The generator builds chunks and knows nothing about the world they will belong to - it has no entity list to add to, and a chunk may well be generated long before anything asks for it. So a pass that builds a village says "a villager belongs here" and the world creates it when the chunk is first loaded.

Deliberately data rather than an Entity: an entity needs a Position, a position needs a world, and a world is exactly what the generator does not have.
