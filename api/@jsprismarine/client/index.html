Behavior ​

Defined in: client/src/bot/behavior/Behavior.ts:27

Something a bot does, once per tick.

Small and composable on purpose: a load test is a question, and the question is usually about one kind of traffic. "Two hundred clients walking" and "two hundred clients chatting" load a server very differently, and being able to ask them separately is worth more than a single realistic-looking simulation that mixes everything.

A behavior must never throw for a reason it could have checked - a bot that dies takes its connection out of the fleet and quietly changes what is being measured.

ITransport ​

Defined in: client/src/net/ITransport.ts:31

What the client needs from whatever carries its bytes.

The seam that lets single player be the same client as multiplayer: over a network this is RakNet over UDP, and in the same process it is a loopback pair, and nothing above here can tell which. It deliberately sits below batching - a transport moves opaque payloads and knows nothing about compression, encryption or packet ids, all of which belong to the session on top of it.
