Class: NativeNetwork ​

Defined in: packages/native-network/src/NativeNetwork.ts:62

The native library, loaded once per thread, and that thread's event queue.

The library is mapped once per process, and each thread that loads it opens a queue of its own, so a worker's peer connections report to the worker. libdatachannel's threads queue events in native memory and send one datagram to a loopback socket here when the queue stops being empty. The socket's handler drains the queue and dispatches each event to the handler registered for its id, so every event reaches JavaScript on the event loop, in order, with no call from a foreign thread.
