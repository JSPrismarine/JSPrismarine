API reference / @jsprismarine/nethernet

@jsprismarine/nethernet ​

NetherNet is the WebRTC transport Minecraft: Bedrock Edition uses beside RakNet. This package implements it, for a server and a client:

  • NetherNetServer turns each client's offer into an answer and keeps the Connection it negotiates. Offers reach it from HTTP signaling, or from LAN discovery once listen binds UDP NETHERNET_LAN_PORT.
  • NetherNetClient opens the reliable and unreliable data channels, sends the offer with every candidate through whatever carries its signals, and connects on the answer. LanDiscovery finds servers on the local network and carries those signals there.
  • Connection splits each message into segments of 10,000 bytes, each led by the number of segments still to come, and joins them back.
  • SignalStructure, encodeDiscoveryPacket and decodeDiscoveryPacket are the wire formats: the signal text, and LAN discovery's packets with their checksum and AES encryption.
  • HttpSignaling, the HTTP signaling a client joining by address uses: GET /v1/join for the server's status and POST /v1/join/{networkId} to trade an SDP offer for an answer.
  • NetherNetIdentity, which signs the a=identity a client requires on every answer, and the SDP helpers it is built on.
  • encodeLanAdvertisement and decodeLanAdvertisement, the advertisement a server answers LAN discovery with.
  • compactEs384, detachedEs384 and verifiesDetachedEs384, the ES384 JSON Web Signatures Bedrock signs its tokens with, made and checked by jose.

The WebRTC stack underneath is a WebRtcDriver. loadNativeDriver loads the one this project ships, libdatachannel in @jsprismarine/native-network, and nothing else here names the library. Where it cannot load, loadNativeDriver throws NetherNetUnavailableError with the platform and the cause.

It knows nothing about Minecraft packets. The 0xFE batch id NetherNet leaves out of each message is the business of whichever transport carries batches over it.

parseUdpPorts() ​

parseUdpPorts(setting, publicIpSetting?): UdpPorts

Defined in: packages/nethernet/src/udpPorts.ts:130

Reads server-udp-ports with server-public-ip as Bedrock Dedicated Server 1.26.70.24 does (docs/research/bds-server-udp-ports.md):

  • Entries are separated by commas; spaces around them and empty entries are ignored, and a repeated entry is fine.
  • Each is a port, start-end, or a public:local mapping of a port or a range onto one of the same length.
  • The local ports of every entry must form one continuous range: adjacent and overlapping ranges merge, and a gap is an error.
  • A deprecated IP:public:local or [IPv6]:public:local prefix still sets the public address, with a warning that names server-public-ip. Two different prefixes, or one that differs from server-public-ip, is an error.
