One file. Any box.

Download the prebuilt server for Linux, macOS or Windows and run it. Its runtime and data are inside, so there is no Node.js, pnpm or Java to install.

chmod +x prismarine-linux-x64
./prismarine-linux-x64

Data first. Code second.

Entities, blocks and commands come from packs. Write code only for what data cannot say. Run your work with pnpm run dev, which restarts the server when your code or pack data changes.

# in a JSPrismarine checkout
pnpm install
pnpm run dev

# or take the pieces into your own project
pnpm add @jsprismarine/molang @jsprismarine/packs
