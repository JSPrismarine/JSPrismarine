Run a server
API reference

  • One command to develop

    pnpm run dev starts the server from source, restarts it when any package changes, and keeps the console UI open across restarts.

  • Published packages

    The protocol, RakNet transport, NBT codec and world storage ship as independent npm packages under @jsprismarine.

  • Single executable

    pnpm run package builds a self-contained binary with Node's single-executable packaging.
