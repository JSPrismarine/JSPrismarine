    Class OfflineAuthProvider

    A login identity that talks to nothing.

    The chain is a single JWT this provider signs with a key it just generated, which is exactly what the real client sends when it is not signed in to Xbox Live. A server in online mode refuses it - there is no XUID to check, and it says so - and a server with online-mode off accepts it, which covers JSPrismarine itself, a LAN game, and the whole of the bot harness.

    The key is generated per instance rather than per login. It is the identity: reusing one across two concurrent connections would have them claim to be the same client, and the encryption handshake would derive the same secret for both.

    Example

    const auth = new OfflineAuthProvider({ displayName: 'Steve' });
    const credentials = await auth.createLoginCredentials({ serverAddress: '127.0.0.1:19132', protocolVersion: 748 });
