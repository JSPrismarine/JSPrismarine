    getPacketCompressionLevel

    • getPacketCompressionLevel(): number

      The zlib level batches are compressed at, clamped to what zlib will actually accept.

      zlib takes -1 (its own default) through 9 and errors on anything else. The value comes straight out of a hand edited config file, and an unchecked 10 reached deflate as a rejection on the chunk sending path - which is nowhere near where the typo was, and used to take the server's tick down with it. Clamping keeps a bad number a bad number rather than an outage.

      Returns number

      • Defined in packages/prismarine/src/config/Config.ts:324

    getPreloadRadius

    • getPreloadRadius(): number

      How many chunks around spawn are generated before the server accepts players.

      A radius of r generates (2r+1)^2 chunks, so the default 10 is 441 - about what the first player will see. Zero skips the preload entirely and generates on demand.

      Returns number

      The preload radius in chunks, as an integer
