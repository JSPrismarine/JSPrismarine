    Class ByteReader

    A cursor over a Buffer.

    Every accessor returns a non-optional value and throws when the buffer is too short, which is what keeps the format code free of buf[i]!. Under noUncheckedIndexedAccess a raw index is number | undefined, and the non-null assertions needed to silence that would also silence a genuine truncation - exactly the bug class a database reader must never paper over.
