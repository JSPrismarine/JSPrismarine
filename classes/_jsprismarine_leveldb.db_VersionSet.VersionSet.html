    Class VersionSet

    Which table files are live, at which level.

    Level 0 is special: its files come straight from memtable flushes, so their key ranges overlap and they must be searched newest first. Every level below holds a sorted, non-overlapping run, which is what lets a lookup binary-search one file per level. Breaking that invariant in a level we write is the one thing here that would corrupt a database for the game as well as for us, so applyEdit checks it.
