A pack counts toward the stable or the beta ranking by the version its manifest declares for
the module. The shape has no beta versions yet, so a beta pack resolves against the newest
stable version of its major version, and members only a beta version has are listed under
"Not in the shape", beside members a script reads on the wrong type. A member a pack adds to
an API type through `declare module` is the pack's own and is not counted. Fields of interfaces,
such as `Vector3.x`, are plain object properties and are ranked apart from members. A pack
counts once per name however often it uses it; Uses counts every occurrence.
