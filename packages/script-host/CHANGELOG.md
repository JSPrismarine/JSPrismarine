- [#3218](https://github.com/JSPrismarine/JSPrismarine/pull/3218) [`f656667`](https://github.com/JSPrismarine/JSPrismarine/commit/f656667b4343bfb2a1f4db9b5ffea4a04924dcdf) Thanks [@filiphsps](https://github.com/filiphsps)! - Behavior pack scripts can now declare the beta Script API versions the pinned Bedrock Dedicated Server ships, such as `@minecraft/server` 2.12.0-beta, `@minecraft/server-ui` 2.4.0-beta and the 1.0.0-beta of `server-gametest`, `server-admin`, `server-net` and `debug-utilities`. A pack that declares one needs the Beta APIs experiment, which a `worlds.<name>` entry turns on with `"experiments": ["gametest"]`.   Version resolution follows BDS: a pack gets a beta only when it is the one beta the server ships, and the version `beta` names that one.   `world.beforeEvents.chatSend` now runs as a guard on a player's chat, before the `chat` event, and a script can cancel the line. `system.beforeEvents.watchdogTerminate` runs before the watchdog shuts the server down for a hang or a stack overflow, and a cancel keeps the server running.
  
  Breaking for code that embeds the script host: `resolveDependency` takes the pack as `{ name, version }`, `ScriptWorld` needs `guardChat`, and `LevelScripts`' `sources` need `chat`, which takes the server's `ChatManager`.

- [#3218](https://github.com/JSPrismarine/JSPrismarine/pull/3218) [`d6c69e4`](https://github.com/JSPrismarine/JSPrismarine/commit/d6c69e43051eb091f0b4a17c0f33799f5944caf3) Thanks [@filiphsps](https://github.com/filiphsps)! - Behavior packs that declare `@minecraft/server-net` can send HTTP requests with `http.get` and `http.request`, build them with `HttpRequest` and `HttpHeader`, read the `HttpResponse`, and cancel them with `http.cancelAll`, as Bedrock Dedicated Server does: the same default headers, no redirects followed, `MalformedUriError` for a scheme other than `http` or `https`, and `InternalHttpRequestError` with the system's error code for a request that fails.
