Java Edition players show with their own skin. Java clients get the signed `textures` property Mojang's session server returned with each Java player's tab list entry, the player's own included, and Bedrock clients get the skin image the server fetches from Mojang's texture server at login, on the classic or slim arms and with old 64x32 skins converted as the Java client converts them. An offline-mode player, or one whose texture the server cannot read in time, keeps the default skin.
