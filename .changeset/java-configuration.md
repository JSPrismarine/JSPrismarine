A logged-in Java Edition client is configured as vanilla 26.3 configures it: the brand, the feature flags, the `minecraft:core` known pack, every registry by id and every tag. The join then ends as the client reaches play, until Java Edition players can play. `@jsprismarine/protocol` gains the configuration packets, `Disconnect (play)`, the 26.3 configuration capture and `capture:java-configuration`, which records it from the pinned server jar, and the Java frame and compression helpers move into it from the server.
