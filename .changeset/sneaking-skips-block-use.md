Sneaking with any item in either hand now uses the item rather than the block, as Java does, so a sneaking player holding a stick no longer opens a chest. A placed chest joins a chest to its side only when both face the same way, and a sneaking placer joins only the chest whose side they clicked, turning to match it, or none.
