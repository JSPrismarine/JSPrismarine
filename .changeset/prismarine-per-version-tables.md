Send each protocol its own captured tables. The protocol 2193 codec now reads `@jsprismarine/bedrock-data/v2193`, including its jigsaw rules and item numbering, and the 2225 codec reads 2225's. The canonical item table, which a stack written outside a session and the server's own membership questions use, is the newest release's (`canonicalItemData`). The pack stack loads the default pinned Bedrock Dedicated Server and `bedrock-samples` when the cache holds other versions too.
