`convertResourcePacks` takes the custom items to draw as a third argument. Each item gets an `items/` definition under its model key and a flat item model over the texture its icon names in `textures/item_texture.json`, and a texture outside `textures/items/` joins the item atlas by name. The report counts the items each pack drew and notes an icon the stack does not hold. `JAVA_PACK_CONVERTER_VERSION` is 2.
