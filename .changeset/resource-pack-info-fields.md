The resource packs a Bedrock client is offered carry every field as a Bedrock Dedicated Server 1.26.60.6 sends it. A pack whose manifest lists the `raytraced` capability is marked ray tracing capable. A pack's subpack is the one the joining level's `world_resource_packs.json` picks, in both the pack list and the pack stack. The `disable-client-vibrant-visuals` setting tells players to use another graphics setting than Vibrant Visuals. The world template is sent at version `0.0.0`, as BDS sends it with packs and without.

An encrypted resource pack goes out with its content key, which the server reads from `<pack folder>.key` beside the pack. The installer keeps the key it finds beside an `.mcpack` or a linked folder, or beside a pack inside an `.mcaddon`, and removes it with the addon. A BDS cannot serve such a pack, since it reads keys only from Marketplace purchases.
