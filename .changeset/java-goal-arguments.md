Add `javaGoalBody` and `matchingJavaGoals` in `@jsprismarine/entity-goals/javaArguments`. `javaGoalBody` writes a Java goal's arguments into the Bedrock goal body that means the same thing, such as `LookAtPlayerGoal`'s look distance into `look_distance` or a `TemptGoal`'s items into `items`.
