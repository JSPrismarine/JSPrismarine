Read a pre-flattening item name in a `has_equipment` filter as the items it became. The llama's carpet interaction asks for `carpet`, which Bedrock now holds as sixteen colored carpet items, so a player holding any carpet could not put it on a llama. `carpet` now matches every color and `carpet:14` the red one, through Bedrock's own legacy item table.
