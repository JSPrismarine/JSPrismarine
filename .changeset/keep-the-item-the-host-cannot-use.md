Keep the item when the host cannot perform the action it would be spent on. `WorldActions` gains an optional `supports(kind)` query, and the empty map, the knowledge book, the nine throwables, a loaded crossbow, shears on an entity and the fishing rod ask it before they consume: a host that says no gets `{}`, the click taken and the stack unchanged, the way an eye of ender with no stronghold in range already answers. The server answers the query from the same table its actor port reports unwritten systems from, and from whether the live entity runtime is attached for projectiles, leads, naming and dyeing, so a right click on nothing no longer spends an empty map or a snowball on a server that draws no maps or throws nothing, and the inventory the client predicted is sent back.
