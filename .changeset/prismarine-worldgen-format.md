The data-driven generator parses world generation documents with the grammar of the Java release the server's content targets, so a server with `content-java-version` set to the 26.4 preview reads its `upscale` density functions and its `noise_settings`. `JavaWorldgenRegistries` carries the release's data pack format, and the registry bundle hands it to the generation workers.
