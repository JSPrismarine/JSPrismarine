`/world list`, `/world create <name> [preset] [seed]`, `/world attach <name>`, `/world detach <name>` and `/world tp <name> [players]` manage the server's levels while it runs and move players between them. Each subcommand needs `jsprismarine.command.world.<subcommand>`, which the bare node and an operator's status cover, and the console may run every one.
