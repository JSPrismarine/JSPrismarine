Villagers, piglins, piglin brutes and copper golems open the wooden doors on their path and close them behind: the runtime answers the brain's path step and door members. Opening a door now writes `open_bit` on both halves, so the upper half's collision box swings with it, and a brain reads the Java block tags of a Bedrock block whose name differs from Java's, such as `minecraft:wooden_door` for `oak_door`.
