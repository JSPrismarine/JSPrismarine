Give `permissions.json` groups and users. A group has a weight, parent groups, nodes and meta; a user has memberships, nodes and meta of their own, and nodes and memberships may expire. Every player holds `default` and every operator holds `operator`. A check resolves the player's own nodes, then their groups heaviest first and each group's parents, where a specific node beats a wildcard and a negation wins a tie. The `level` meta sets a player's command level, which the command list and the abilities a client receives now follow; an operator still runs at 4. The file gains `schemaVersion` 2 with `users` filed under `xbox`, `java` and `offline`; a file without it migrates at startup, with the old file kept as `permissions.json.bak` and each `players` entry waiting under `pending` until a login with its UUID claims it. The server reads the file again on `/reload` and when it changes on disk. Every JSON file the server owns, `ops.json`, `banned-players.json` and player data included, is now written through a temporary file that replaces it only once complete and keeps its mode, so a failed write leaves the file as it was. `PermissionManager` gains `has`, `metaOf`, `groupsOf`, `primaryGroupOf`, `commandLevelOf`, the group and user writes and `onChange`; `getPermissions`, `setPermissions` and `getDefaultPermissions` are gone, and the check interface takes `hasPermission(node)` instead of `getPermissions()`. A fresh file no longer grants `*` to a hard-coded owner UUID; an owner who relied on it runs `/op` from the console once, and an entry migrated from an old file waits under `pending` until that player logs in.
