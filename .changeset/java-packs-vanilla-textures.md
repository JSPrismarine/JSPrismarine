A Bedrock pack that retextures a vanilla block or item retextures it on Java too: `convertResourcePacks` writes the texture, and its flipbook animation, over each Java texture it is, from a table matched pixel for pixel between the pinned Java client jar and Mojang's vanilla Bedrock resource pack. A vanilla Bedrock texture with no Java counterpart, such as a Bedrock-only block's, is reported. `decodePng` reads PNG files of every color type and bit depth, interlaced or not.
