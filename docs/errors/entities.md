## `ENTITIES_DECLARES_ITS_COMPONENT_STATE_TWICE`

`{component} declares its component state twice`

Thrown as `EntitiesErrors.DeclaresItsComponentStateTwice`, which extends `Error`.

An entity component registered its state twice. Each component declares its state once.
