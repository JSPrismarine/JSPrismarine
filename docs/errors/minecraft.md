# @jsprismarine/minecraft errors

These are the errors `@jsprismarine/minecraft` throws. [The error reference](README.md) explains how to read an entry.

<!-- fact:errors.page.minecraft -->
## `MINECRAFT_GAMETYPE_INVALID`

`Gametype "{gametype}" is not a valid game type.`

Thrown as `MinecraftErrors.GametypeInvalid`, which extends `Error`.

A game mode was given by a name or a number that names none of the four.
