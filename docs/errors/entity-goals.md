## `ENTITY_GOALS_TEST_ENTITY_DID_NOT_LOAD`

`{diagnostics}`

Thrown as `EntityGoalsErrors.TestEntityDidNotLoad`, which extends `Error`.

The goal harness could not load its test entity. The message joins the load's error diagnostics with `; `.
